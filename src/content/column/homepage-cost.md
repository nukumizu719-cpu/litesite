「ホームページ制作 費用」で調べると、数万円のものから数百万円のものまで、金額の幅が大きすぎて判断に困ります。この差は、ほとんどが「何を含んでいるか」の違いです。

この記事では、ホームページにかかるお金の内訳と、見積もりを受け取ったときに確認しておきたいポイントをまとめます。

## ホームページにかかるお金は「作る費用」と「持ち続ける費用」

ホームページの費用は、大きく2つに分かれます。

- **制作費（初期費用）**：ホームページを作って公開するまでにかかる費用
- **維持費（ランニングコスト）**：公開したホームページを持ち続けるためにかかる費用

見積もりでは制作費に目が行きがちですが、ホームページは公開してからの年月のほうが長いものです。比べるときは、**数年間持ち続けた場合の合計**で考えるのがおすすめです。

### 制作費の中身

制作費には、主に次のような作業が含まれます。

| 作業 | 内容 |
| --- | --- |
| 企画・構成 | 目的やお客様像を整理し、ページ構成を決める |
| デザイン | 見た目を作る。テンプレートかオリジナルかで差が出る |
| コーディング | デザインを実際に動くページにする |
| 原稿・写真 | 文章の作成や写真撮影。依頼するか自分で用意するか |
| 機能 | お問い合わせフォーム、予約、ネットショップなど |
| 公開作業 | ドメインの接続、SSL化、アクセス解析の設定など |

### 維持費の中身

公開後は、次のような費用がかかります。

- **ドメイン代**：「〇〇.jp」などのインターネット上の住所。年に数千円程度
- **サーバー代**：ホームページのデータを置いておく場所。共用のレンタルサーバーなら月数百円〜
- **保守・管理費**：制作会社に更新作業や管理を任せる場合の費用。会社によって内容も金額もさまざま

WordPressで作ったホームページは、本体やプラグインの更新作業が定期的に必要なため、保守・管理費を毎月払う契約になっていることが多くあります。

## 金額が変わる主な理由

同じ「ホームページ制作」でも金額が大きく変わるのは、次のような違いがあるからです。

1. **ページ数**：ページが増えるほど、デザイン・コーディング・原稿の量が増えます
2. **デザイン**：テンプレートを使うか、一からデザインするか
3. **原稿と写真**：自分で用意するか、ライターやカメラマンに頼むか
4. **機能**：予約システムやネットショップ、多言語対応などは費用が上がります
5. **制作体制**：ディレクター・デザイナー・エンジニアが分業する会社と、個人で一貫して作る場合では、人件費のかかり方が違います

## 見積もりで確認したい5つのこと

見積もりを受け取ったら、金額と一緒に次の5つを確認しておくと、あとから「そんなはずじゃなかった」を防げます。

### 1. 何ページ分の料金か

見積もりの金額が何ページ分なのか、ページを追加したい場合はいくらかかるのかを確認しましょう。

### 2. 原稿・写真は誰が用意するのか

文章や写真を制作側が用意する前提なのか、自分で用意する前提なのかで、手間も費用も大きく変わります。

### 3. 修正は何回まで含まれるか

デザインや文章の修正に回数の上限があるかどうか。上限を超えた場合の費用も確認しておきます。

### 4. 公開後の月額費用と、その中身

月額費用がある場合は、その金額で何をしてもらえるのかを確認しましょう。「更新作業は別料金だった」というのはよくある行き違いです。契約期間の縛りや、途中で解約する場合の条件もあわせて確認しておくと安心です。

### 5. ドメインとサーバーは誰の名義か

意外と見落とされがちですが、とても大事なポイントです。ドメインやサーバーが制作会社の名義だと、契約をやめたときにホームページや、使い慣れたドメインを持ち出せないことがあります。**自分の名義で持てるのか、解約したときにどうなるのか**を事前に確認しておきましょう。

## まとめ

- ホームページの費用は「制作費」と「維持費」に分けて、数年分の合計で比べる
- 金額の差は、ページ数・デザイン・原稿・機能・制作体制の違いから生まれる
- 見積もりでは、ページ数・原稿・修正回数・月額の中身・名義の5つを確認する
